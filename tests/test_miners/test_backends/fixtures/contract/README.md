# Collection contract fixtures

Responses replayed by `test_collection_contract.py`. Each directory holds one
response per API command. `stats-new-api` and `summary-new-api` are the
`new_api` requests used by the Nonce adapter.

| Directory | Source |
| --- | --- |
| `stock-s21xp` | Stock Antminer S21 XP firmware (`uart_trans.1.3`), recorded on a production unit |
| `nonce-s21plus` | Nonce firmware on an S21+ lab unit, CGMiner `4.13.8+g4cc16133ef77`, recorded |
| `nonce-s21xp-synthetic` | Synthetic. Generated by the noncehq/cgminer API dispatch test with the `s21xp_A3HB70503` profile, 91 chips per board and PSU info code `0x1F09`; `version` mirrors the version fields asserted by that test |

Serial numbers, MAC addresses, pool hosts, worker names and IP addresses in the
recorded samples are replaced with fixture values. All other fields are
unmodified device output. Replace the synthetic XP sample with a recorded one
once a Nonce S21 XP capture is available.
